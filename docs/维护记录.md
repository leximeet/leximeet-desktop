# 维护记录

## 1.0.2 Windows / Linux

- 发布矩阵增加 Windows x64（NSIS）与 Linux x64（AppImage + deb）；三端齐套后才发 1.0.2。
- 本机通道：Windows 命名管道 + 令牌 + DACL；描述符 `leximeet.{lmcp,mcp}-transport/1`。LMCP 1.0.0 快照未改。
- Windows 启动器为随包 PE stub；私有文件走 NTFS ACL。Linux 通知与 XDG 开机自启为尽力支持。
- CI 矩阵 macos-15 / windows-2025 / ubuntu-24.04；干净 runner 上 L2 安装冒烟。Windows 不签名，文档写明 SmartScreen。
- 修正 macOS 系统 `/tmp` `/var` 前缀软链接误拒、core-cross 缺少词典、lint 未检出 Core 文档，以及 Windows 进程组/打开文件导致的单元测试挂死。
- Windows 隔离目录回收改为检查 ACL（不含 Everyone / Users / Authenticated Users），并在 windows-2025 上跑真实 icacls 用例；不再只跳过 POSIX 0o077。
- 跳过 Win/macOS 的 POSIX 进程组用例后，各平台增加「停止后子进程确实退出」测试：Windows `taskkill /T`，macOS 按 PID 与子进程，Linux 保留进程组及父进程先退出场景。
- NTFS 对文件不再套目录继承 ACE；electron-builder 26 的 Linux `packageName` 移到 `deb`。ASAR 物料按归档内实际键抽取。
- Linux `.deb` 写入 `linux.maintainer` 与 `homepage`，满足 FpmTarget 对维护者邮箱和项目主页的要求。Windows core-cross 仅在单元/Core 测试前把工作区 / TEMP / `java.exe` 加入 Defender 排除，并把 `TEMP` 指到 `.runtime/ci-tmp`；不注入 `JAVA_TOOL_OPTIONS`，以免污染 Core 子进程 stderr。不改 Core 的 15 秒预算。
- 产品等待 Core 启动在 Windows 上加宽到 120 秒（POSIX 仍 45 秒），给 Defender 首次扫描 Jar/JRE 留有界余量，不自动重试。install-smoke 的 Windows 任务确认实时保护开启，不排除 Defender。
- Core 启动失败分类把 stderr 重定向到运行副本文件再读。Windows 用 `java.exe` + 隐藏窗口，不用 `javaw`（会脱离父进程，丢失诊断且 stop 杀不到）。父进程立刻关掉自己的 stderr 句柄，避免 `close` 死锁。`stop` 立刻结束进程树并拆掉 stdout。
- Windows 用例里的 `icacls` / `taskkill` 也走 `windowsSystem32Binary`，不给测试补 PATH。`powershell.exe` 单独解析到 `System32\\WindowsPowerShell\\v1.0`，`windowsSystem32Binary` 拒绝把它套进 System32 根目录。
- 命名管道 DACL 用 `SetNamedSecurityInfo(SE_FILE_OBJECT, \\\\.\\pipe\\<名>)`，不再只走 `SE_KERNEL_OBJECT`（会 ERROR_FILE_NOT_FOUND，fail-closed 后 Core/MCP 描述符超时）。收紧后回读 SDDL；断言允许 whoami 与 `WindowsIdentity` 的用户 SID 不一致，以及 SDDL 把管理员 RID 500 写成 `LA`（也可认 `BA`），只要没有 Everyone / Users / 匿名；传输单测不再要求回读必须含 `S-1-5-` 字面量。LMCP / MCP `start` 失败写 stderr；冒烟失败时打印 `logs/`。LMCP 接受连接与查询状态时清掉已销毁或半开仍占槽的套接字，避免 Windows 命名管道上握手挂死。生命周期用例在 Windows 上复用连接前等待管道实例回收。`test:lmcp:transport` 门禁 420 秒。撤销登记时清单 ACL 不再私有也视为已变更。Windows 登记用例核对 PE stub 与 `.launch`，不在 exe 里找 `NODE_OPTIONS`。设置页与 `inspectClient` 转发 `projectDir` / `resourcesPath`；未指定查找根时回退打包 `resources` 与仓库 `.runtime/native`。隔离 `homeDir` 不误用本机 `APPDATA` / `XDG_CONFIG_HOME`。读取 Codex TOML 的 `command` 时反转义，Windows 路径才能对上磁盘。MCP 用例按 PE + `.launch` 断言；残留 UDS 夹具只在 POSIX 跑。NSIS 冒烟在描述符已写出后，清理隔离目录遇 `EPERM`/`EBUSY` 不当成失败。
- `ci.yml` 不再用单一 desktop 矩阵：macOS 三分片并行；Win/Linux 测试与打包分开；install-smoke 按平台 `needs` 打包作业。lint 5 分钟且不阻塞。启用 npm / Maven / Electron 缓存。
- PE stub 编译到 `.runtime/native`，extraResources 从该路径打包；Windows 上未跟踪的 `.exe`/`.obj` 不再把 `package:dist` 判脏。`test:package:desktop` 自行准备 Full 物料。install-smoke 不再用 `!cancelled()` 在打包失败后空跑。Windows Core `stop` 立刻结束进程树并拆掉 stdout。
- Windows `stop` 按 `-Dleximeet.instance` 回收 JVM；成功占住目录后才按资料目录回收，避免 `DATA_IN_USE` 启动失败误杀持锁原进程。CIM 先按映像名缩小。PowerShell 路径用单引号或环境变量，不用 `JSON.stringify` 嵌双引号。`icacls` / `reg.exe` / `whoami.exe` / `taskkill.exe` 走 `System32\\<名字>.exe`；`powershell.exe` 走 `System32\\WindowsPowerShell\\v1.0`。Host catch 写出原始错误。Native 测试每例独有 `hostName`，unregister 放进 `finally`。命名管道 ACL 收紧失败则关闭监听（fail-closed），回读 DACL 断言无 Everyone / Users / 匿名。进程树带父 PID；`showErrorBox` 拦截写原始错误。词典下载重试并缓存，不回退本机代理端口。macOS verify 的 `test:desktop` 预算 900 秒。集成测试清理遇 `EPERM` 忽略。Windows 冷启动 `mvn -version` 探测加宽并重试。CI 的 `.runtime/ci-tmp` 先收紧 ACL；LMCP 隔离夹具按私有目录创建，网关测试连 `path`。Host 白名单补 `powershell.cjs`。NSIS 冒烟禁用 GPU、先创建隔离 `AppData`。
- 文档入口见 [1.0.2 发行说明](版本/1.0.2.md)。Core gitlink 仍为 `a98afa8`，本轮不改 Core。

## 维护原则

行为变化时同步对应文档、测试和 CHANGELOG。不要在多个地方复制完整积分或协议规则；共享规则由 Core 和 Connector 维护，本仓解释实际消费与系统能力。验证结果需写明源码、真实应用包、模拟系统适配器和人工操作各自的范围。
