## 维护原则

行为变化时同步对应文档、测试和 CHANGELOG。不要在多个地方复制完整积分或协议规则；共享规则由 Core 和 Connector 维护，本仓解释实际消费与系统能力。验证结果需写明源码、真实应用包、模拟系统适配器和人工操作各自的范围。
