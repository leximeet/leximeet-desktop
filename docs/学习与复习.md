# 学习与复习

积分表示学习进度，FSRS 决定自动复习建议；采集和普通阅读不计分。学习规划可选，主动练习不受提醒窗口限制。

## 学习规划

学习规划由一个学习目标和一份每日计划组成。它是可选的：没有规划时，仍可记录单词、整理单词本和自由练习。

## 设置与调整

1. 在「学习规划」点击「设置学习规划」。
2. 选择考试 / 专业主题词库，或当前本地词典；可搜索全部主题。教学默认预选雅思。
3. 下一步设置每天新学、每天复习、提醒开关和时间范围，查看接下来 5 天的新词安排。
4. 点击「保存学习规划」后，目标与计划一起生效。关闭、取消或回到上一步不会提前改动当前规划。

新建默认新学 10、复习 20；调整当前计划保留未修改项。新学范围 1–50，复习 0–500。每天复习为 0 表示暂不安排到期复习名额，自由练习仍可使用。

概览页展示当前目标、新学与复习额度、提醒和后续安排。「调整计划」直接编辑每日安排，保留目标、计划身份和开始日；「更换学习目标」需要重新完成两步流程，保存后替换当前规划，个人资料与学习历史仍保留。词库中心的「设为学习目标」也会进入这份草稿，不单独写入目标。

## 预览与提醒

预览只统计所选目标中尚未初学的新词。今天先扣除已用新学额度，接下来的日期按学习时区计算；今天额度用完时可以显示 0。预计天数是新词安排，不是掌握全部词的承诺。到期复习由记忆排程和每日上限决定。

桌面端额外提供「学习提醒」及默认 08:00–20:00 的时间范围；关闭后隐藏时间输入。提醒窗口不限制练习时间。窗口内约每 30 分钟随机提醒一次，实际间隔 25–35 分钟，无每日 3 次上限；仅有任务且应用不在前台时投递。频率与通知练习类型展示在「设置 → 学习提醒」，学习规划不放间隔或模式选择。

## 数据与异常

Core 在同一个事务内保存目标、额度、提醒开关与时间范围；通知模式由设置页另行保存，不会被规划保存覆盖。输入无效、查询失败或其他窗口已修改当前规划时，不会只保存部分内容；发生冲突后保留草稿，需要重新打开并确认最新内容。预览查询不创建词条，也不改变学习记录。

新规划保存 `planId/startedOn/savedAt`，公共词典数据不复制进个人词库。随机提醒安排由 Main 管理，学习规则为 v2。当前直接初始化 schema 100，不转换历史测试库；未知格式拒绝并保留，见[收尾政策](发布与路线图.md)。

规划交互与 Browser 独立端一致。插件连接后，规划入口打开 Desktop，由本机 Core 保存；LMCP 1.0.0 不再提供远程规划编辑或首次合并。独立设备将来按 LMSP 同步，不能凭相似 UI 宣称已经云同步，详见[学习与设备运行规范](架构与数据模型.md)。

在「设置 → 学习提醒」可选择六种模式中的一种或多种，默认看词选义；支持的原生交互及限制见[系统通知练习](#通知中的单题练习)。初学完成以首次跨越 20 为准，预览表示建议安排，不承诺每天一定完成这些词。

## 积分、状态与调度

词遇用积分展示学习进度，用 FSRS 安排自动复习。两者使用同一次真实练习，各自负责不同的事。完整开发约定见 [Core 统一学习规则 v2](../core-java/docs/统一学习规则.md)。

## 分数与状态

新词从 **10 分**开始，表示尚未判断掌握程度。被安排到今日任务后显示待学习；开始练习后为学习中。**首次达到至少 20 分完成初学**；**达到 30 分进入已熟悉休息期**。

| 列表筛选 | 含义                                               |
| -------- | -------------------------------------------------- |
| 全部     | 当前范围的所有词                                   |
| 未学习   | 尚未开始；其中今日队列已安排的词显示「待学习」     |
| 学习中   | 已开始，尚未首次达到 20 分                         |
| 待复习   | 曾完成初学，目前未在熟悉休息期；到期前也可主动练习 |
| 已熟悉   | 到过 30，仍在休息期；衰减至 29–21 也在这一类       |
| 不熟悉   | 当前为 0 分，可同时属于学习中或待复习              |

筛选在全量词库上执行，再计数和分页，可与搜索、词本、词性组合。单词从 20 降回 10 或 0 不会丢失初学完成经历，也不会再次消耗新学名额。

## 六种练习

| 练习     | 首次正确或熟练反馈 |
| -------- | -----------------: |
| 单词列表 |                 +1 |
| 看词选义 |                 +1 |
| 单词临摹 |                 +1 |
| 单词默写 |                 +2 |
| 听音辨词 |                 +1 |
| 语境填空 |                 +2 |

错误、不熟悉反馈或在练习中查看遮挡答案 −1；最低 0、最高 30。同一道题只结算首次有效反馈；提示后订正不补分。取消每天最多 +4 分的旧限制。普通词卡阅读、发音、采集不扣分或加分。

临摹可以累积分数至 20，但不证明独立回忆，因此不会伪造 FSRS 成功；系统会在明日安排首次回忆验证。独立答题与列表明确自评才提供调度证据。

## 满分后什么时候复习

满分后保护完整 3 天，接着每完整 2 天减 1 分：无其他练习时第 5 天 29、第 7 天 28、第 23 天 20；离线时间照常计算，自动衰减不低于 20。自然衰减不是答错，不生成 FSRS 失败。

只有从不足 30 再次升到 30 才重新计时。30→30、25→26 不重置。休息期内主动答错，分数仍高于 20 时继续休息；降至 20 或以下才回到复习池。

复习池和到期队列不同：首次完成初学的词最早明天自动复习；休息结束的词当时恢复资格。再检查 FSRS 建议时间，已到期才进入今日自动安排。**主动练习始终可用**。

## 练习反馈与连续操作

看词选义和其他单题练习答对并确认保存后，停留一秒显示结果，再自动进入下一词。错误保留当前题，可订正或查看提示；同题首次反馈仍按规则计分，不借订正再加一分。关闭「自动进入下一词」后，使用「熟记」手动继续。

临摹未输入部分是淡色幽灵提示，已输入正确部分清晰显示；默写不提供未输入字母。切换模式、范围、重开或离开页面会取消旧题定时器，未知回执和保存失败必须先恢复原反馈。这个等待只改善阅读节奏，不改变积分、学习状态、每日完成量或 FSRS。

## 今日完成量

- 新学完成：今天第一次跨越 20 分的不同词数。例如 19 +2=21 也完成。
- 复习完成：复习资格已生效后，今天成功独立回忆的不同词数，不要求 FSRS 已到期；临摹不冒充有效回忆。
- 练习记录：未撤销的反馈记录数（包含订正），与独立题数、完成词数分开。同日新学完成不重复计一个旧词复习。

答错不计入成功完成量；成功后又答错，仍可安排短期巩固，但同一个词不会重复计入完成数。已开始的初学优先继续，更换目标不删除历史；自由练习可以超出每日建议数量。

## 首次发布前的测试资料

新建资料直接使用 v2。正式 1.0.0 发布前不兼容 0.x / rc 测试库，不再要求转换旧分数或确认重新评估；使用一键脚本创建新隔离实例。当前已移除旧迁移确认与解释器，直接使用 schema 100；未知格式拒绝并保留。正常使用中的学习事件、退出重启和插件封存恢复仍要可靠保存；正式 1.0.0 以后的真实资料才进入版本兼容承诺。详见[收尾与接入边界](发布与路线图.md)。

## 通知中的单题练习

在「学习规划 → 调整计划」开启学习提醒并设置时间范围；在「设置 → 学习提醒」选择通知中的练习，默认看词选义，可多选轮换。频率显示为“约 30 分钟随机提醒”，无须设置。每次只发一道题，回答与练习中心使用同一计分标准。

## 怎样使用

- 看词选义：通知显示英文，从系统动作菜单选释义。
- 单词列表：回想后选熟练 / 不熟悉，或查看释义；首次操作计分。
- 临摹、默写、语境填空：展开系统回复框，输入单词并提交。
- 听音辨词：先点击「播放发音」，音频结束后出现回复题，输入听到的单词。当前播放适配为 macOS。

关闭、忽略、空回复、投递失败或过期都不计分。题目 30 分钟后过期，不会像剪贴板采集一样超时自动处理。重复系统回调只记一次；已出的题目不会因为后来更改设置或词典而改变答案。

## 时间与频率

默认时间范围 08:00–20:00。每次在 25–35 分钟中均匀抽取下次间隔，平均 30 分钟；不提供间隔选择，也不再限制每天 3 次。12 小时持续后台、有任务时大约 24 次，不是必须发满的次数。须有今日候选任务、计划及提醒启用、应用不在前台。FSRS 到期控制单词是否可自动复习；随机间隔控制打扰频率，两者不互相替代。

- 启动、进入时间窗口、恢复任务或更改时间范围后先等待一个随机间隔，不立即发题。
- 下次时刻原子保存；正常重启沿用它，不反复抽签或重复投递。
- 前台到点时跳过；休眠或关闭错过超过 2 分钟时重新安排，不追补、不连发积压。时间窗口结束后清除待提醒时刻。
- 投递意图先保存再通知。投递失败也等到下次间隔，不立即重试。次数只用于本机投递诊断，不代表已显示或完成学习。

先选词，再从用户选定的可用模式中轮换。缺少语境、释义选项不足、系统不支持某种输入时保留任务；没有可用的选定模式会报告原因，不私自改成未选模式。通知显示成功不等于用户已看到，更不等于完成学习。

## 原生能力与验收

macOS 使用 Electron 原生 Notification 按钮及回复框；不是 HTML 弹窗。系统通知样式、动作展开和权限由 macOS 管理。Electron 42+ 要求签名应用；用一键脚本启动的独立签名验收应用进行实际通知检查，见[本地测试启动](本地测试启动.md)。权限不足不自动弹出代替窗口。点击通知正文才由用户主动打开主应用。

Windows 提供按钮和回复适配，尚未完成真实系统验收；当前听音播放适配不支持 Windows。Linux 尚无通知内答题适配，会报告能力不足，仍可手动使用练习中心。不能因为 Electron 提供 Notification 类就宣称六种模式跨平台验收完成。

自动化使用隔离 Electron、真实 Core/SQLite 和替换的 OS 投递器，验证出题、动作/回复、失败、中断与幂等。真实通知 banner、权限、听音和系统回复体验另行人工验收；此边界不能用截图或 mock 回调替代。

## 开发边界

`StudyReminder` 管时间窗口、25–35 分钟随机间隔、前台免打扰与持久化节流；`StudyNotifications` 将固定题目映射为原生动作；`DesktopReminderPractice` 保存题目并调用 `DesktopPractice`；分数与 FSRS 留在 Core。

已投递通知的崩溃恢复通过通知中心历史重新绑定 Core 中尚未过期的题目，不把整个未答题表重新弹一次。正常退出撤回本进程持有的练习通知。关闭通知没有答题副作用。

当前个人数据库直接使用 schema 100，提醒基准为 30 分钟，不做旧测试库间隔转换或学习确认。设备的下次随机投递时刻不作为跨端同步数据。普通练习和通知共享 Core 冻结题目、判题及事件规则，投递本身不产生学习事实。

API 和共享规则向量见 [Core 统一学习规则](../core-java/docs/统一学习规则.md)。Browser 将来可使用 `notifications/alarms` 做平台适配，但不得另写一份计分、到期或超时扣分逻辑。

已有独立记忆且尚未到 FSRS 建议时间时，提前成功增加积分，并按已生效的复习资格计入当日完成，但不延后原排期；真实失败仍可安排短期巩固。不能把主动重复练对转成无限延后自动复习。

## 独立模式进度与只读预测

同一范围内，列表、选义、临摹、默写、听音与填空各自保存位置和草稿。重开刷新当前模式词范围而保留其他模式进度、已保存积分与记录。提示显示幽灵字母，原输入保持可编辑；重新打开已确认正确题时仍可自动继续，不停在只读输入。

规划曲线推算“第一次达到20分的目标词数量”，不推算熟悉程度或 FSRS。额外采集的词优先进入今日任务，因此当天安排的目标新词可能为零。完整示例见[词库与学习预测](词库与学习预测.md)。
