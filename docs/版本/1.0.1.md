# LexiMeet Desktop 1.0.1

在 1.0.0 本机词典、练习和浏览器连接之上，增加「AI 助手连接」：把本机词典、单词本和学习进度提供给 Cursor、Codex、Claude Code。使用官方 MCP，与插件用的 LMCP 1.0.0 分开。

## 主要功能

- 四件路由式工具：`leximeet_help` / `leximeet_describe` / `leximeet_query` / `leximeet_write(add_to_vocab)`。
- 默认只读。唯一写入是加入单词本，设置里授权，可随时撤销。不允许助手提交复习判题。
- 设置页：检测、一键接入、测试连接、断开（只删词遇写入的键）和写入开关。
- 客户端只配置稳定启动脚本绝对路径，不含 Core 令牌、端口或 SQLite。
- 桌面未运行或残留套接字无人监听时，`initialize` 仍可完成握手；工具调用返回 `DESKTOP_NOT_RUNNING`，不自动打开应用。

## 下载与安装

[GitHub Release](https://github.com/leximeet/leximeet-desktop/releases/tag/1.0.1) 提供 **macOS arm64** 的 `LexiMeet-1.0.1-mac-arm64.dmg` 和 `.zip`。DMG 打开后将应用拖入 Applications；ZIP 是相同平台的应用归档。应用自带裁剪 JRE 和 Core Text 词典，无需另装 Java。

本版使用 ad-hoc 签名，**没有 Developer ID 签名或 Apple 公证**。macOS 可能要求用户在“隐私与安全性”中确认打开可信下载；不要全局关闭 Gatekeeper。Windows/Linux、macOS Intel 及正式商店安装未在本版声明为已验收平台。

## 对应源码与验证

附件包含 `desktop-source.tar.gz`、`core-source.tar.gz`、`LICENSE`、`SOURCE_METADATA.json`、`BUILD-MANIFEST.json`、`RELEASE-MANIFEST.json` 和 `SHA256SUMS`。两个源码包共同组成应用的完整对应源码；GitHub 自动生成的源码 ZIP 不展开 Core 子模块。

下载附件到同一目录后执行 `shasum -a 256 -c SHA256SUMS`。源码组合、Core gitlink、资源版本、签名与实际安装验证结果由清单记录。`BUILD-MANIFEST.json` 的 `distribution.published` 是构建时状态；是否公开以 Release 页面为准。

标签流水线先运行完整 Desktop 门禁，再构建安装器、核对物料并从 DMG 隔离安装和启动；发布任务复用这些原样安装包。系统通知权限、声音、输入法和真人体验，以及真实三家助手客户端的一键接入，仍须人工验收。

## 版本边界

无需登录，没有账号或云同步；云同步属于 2.0.0 路线。正式资料继续使用稳定的 `workspaces/v1` 空间。当前只支持 macOS arm64；一键接入只做 Cursor、Codex、Claude Code。
