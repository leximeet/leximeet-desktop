# LexiMeet Desktop 1.0.2

在 1.0.1「AI 助手连接」之上，把已验收的 macOS arm64 扩到 **Windows x64** 和 **Linux x64**。三个平台的安装包都齐全、都经过本轮安装验收后才发本版，不分平台先发。

## 主要功能

- 本机通道：macOS / Linux 继续同用户 UDS；Windows 使用命名管道 + 传输令牌 + 收紧 DACL，不降级到回环 TCP。
- 描述符新增 `leximeet.{lmcp,mcp}-transport/1`（`kind: uds | named-pipe`）；旧 `*-uds/1` 仍当作 UDS。LMCP 1.0.0 冻结快照未改。
- Windows MCP / Native Host 启动器是随包 PE stub（`ELECTRON_RUN_AS_NODE` + `.launch` 旁路），官方 MCP SDK `shell:false` 可直接拉起。
- Native Messaging：Windows 写 HKCU（先 32 后 64 视图）；Linux / macOS 写用户级清单文件。浏览器范围仍是 Chrome + Edge。
- 私有文件：POSIX 保持 0600；Windows NTFS 用 ACL 去掉 Everyone / Users / Authenticated Users。隔离目录回收同样检查 ACL，不是只跳过 POSIX 权限位。
- Linux 系统通知与开机自启（XDG autostart）为**尽力支持**，不宣称覆盖全部桌面环境。
- 一键接入仍只写官方默认路径：`~/.cursor/mcp.json`、`~/.codex/config.toml`、`~/.claude.json`。不认 `CODEX_HOME`。

## 下载与安装

[GitHub Release](https://github.com/leximeet/leximeet-desktop/releases/tag/1.0.2) 在三端齐套后提供：

| 平台    | 架构  | 安装包                                         |
| ------- | ----- | ---------------------------------------------- |
| macOS   | arm64 | `LexiMeet-1.0.2-mac-arm64.dmg`、`.zip`         |
| Windows | x64   | `LexiMeet-1.0.2-win-x64.exe`（NSIS，当前用户） |
| Linux   | x64   | `LexiMeet-1.0.2-linux-x64.AppImage`、`.deb`    |

应用自带裁剪 JRE 和 Core Text 词典，无需另装 Java。资料分别落在：

- macOS：`~/Library/Application Support/LexiMeet/workspaces/v1`
- Windows：`%APPDATA%\LexiMeet\workspaces\v1`
- Linux：`~/.config/LexiMeet/workspaces/v1`

覆盖安装不删除用户资料。卸载（NSIS / `apt remove leximeet`）同样保留资料。

### 签名与系统提示

- **macOS**：继续 ad-hoc 签名（`identity: "-"`），**没有 Developer ID 或公证**。首次打开可能要在“隐私与安全性”中确认；不要全局关闭 Gatekeeper。
- **Windows**：本版**不代码签名**。从浏览器下载后 SmartScreen 会提示“未知发布者 / Windows 已保护你的电脑”。在确认校验和（`SHA256SUMS`）后，可选择“更多信息 → 仍要运行”。企业策略若禁止未签名程序，需管理员放行。
- **Linux**：包内不签名。维护者对 `SHA256SUMS` 做核验。无 FUSE 时可用 `chmod +x` 后加 `--appimage-extract-and-run`，或安装 `libfuse2` / `libfuse2t64`。deb 安装：`sudo apt install ./LexiMeet-1.0.2-linux-x64.deb`。

更新 feed 为同 Release 的 `latest.json`，按 `darwin-arm64` / `win32-x64` / `linux-x64` 取资源；应用只下载校验、提示手动安装，不自动替换。

## 对应源码与验证

附件包含三端安装包、`desktop-source.tar.gz`、`core-source.tar.gz`、`LICENSE`、`SOURCE_METADATA.json`、各平台 `BUILD-MANIFEST-<platform>-<arch>.json`、`latest.json`、`RELEASE-MANIFEST.json` 和 `SHA256SUMS`。两个源码包共同组成完整对应源码。

下载到同一目录后执行 `shasum -a 256 -c SHA256SUMS`（Windows 可用 `Get-FileHash` 对照）。标签流水线在 macos-15 / windows-2025 / ubuntu-24.04 上分别构建，并在干净 runner 上做 L2 安装冒烟（NSIS `/S`、`apt install ./x.deb`、AppImage → 启动 → Core 健康 → MCP SDK → 卸载）。发布任务三端齐套后才合并附件。

七天旅程、真实 Chrome / Edge 插件、真实 Cursor / Codex / Claude Code 一键接入，以及 SmartScreen / Gatekeeper / 系统通知听感，仍须人工验收。

## 版本边界

无需登录，没有账号或云同步；云同步属于 2.0.0。正式资料继续使用 `workspaces/v1`。一键接入只做 Cursor、Codex、Claude Code。不做 Windows/Linux arm64、macOS Intel、Firefox、Windsurf、Claude Desktop、VS Code。不为未发布的 0.x 资料格式写兼容。
