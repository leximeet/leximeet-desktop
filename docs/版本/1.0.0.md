# LexiMeet Desktop 1.0.0

词遇的首个正式桌面版本。单词、笔记、语境和学习进度保存在本机；浏览器插件确认连接后，网页查词和采集使用桌面资料。

## 主要功能

- 学习规划：可选目标，每日默认新学 10 词、复习 20 词，查看具体候选和进度预测。
- 六种练习：各模式分别保存进度和草稿；正确作答显示一秒后继续，提示使用幽灵文字，重新开始保留已记成绩。
- 学习规则：初始 10 分，20 分完成初学，30 分进入熟悉休息期；积分表示状态，FSRS 安排复习。
- 我的词库：目标引用与遇见词、多词本、笔记、筛选、批量整理和回收恢复。
- 安全采集：剪贴板匹配目标、插件和手动采集；默认单句限长、脱敏、七天忽略大小写的重复语境检查。
- 本地连接：发现、用户确认、权威读卡、幂等采集、断开和撤权；连接不合并两端独立资料。

## 下载与安装

[GitHub Release](https://github.com/leximeet/leximeet-desktop/releases/tag/1.0.0) 提供 **macOS arm64** 的 `LexiMeet-1.0.0-mac-arm64.dmg` 和 `.zip`。DMG 打开后将应用拖入 Applications；ZIP 是相同平台的应用归档。应用自带裁剪 JRE 和 Core Text 词典，无需另装 Java。

本版使用 ad-hoc 签名，**没有 Developer ID 签名或 Apple 公证**。macOS 可能要求用户在“隐私与安全性”中确认打开可信下载；不要全局关闭 Gatekeeper。Windows/Linux、macOS Intel 及正式商店安装未在本版声明为已验收平台。

## 对应源码与验证

附件包含 `desktop-source.tar.gz`、`core-source.tar.gz`、`LICENSE`、`SOURCE_METADATA.json`、`BUILD-MANIFEST.json`、`RELEASE-MANIFEST.json` 和 `SHA256SUMS`。两个源码包共同组成应用的完整对应源码；GitHub 自动生成的源码 ZIP 不展开 Core 子模块。

下载附件到同一目录后执行 `shasum -a 256 -c SHA256SUMS`。源码组合、Core gitlink、资源版本、签名与实际安装验证结果由清单记录。`BUILD-MANIFEST.json` 的 `distribution.published` 是构建时状态；是否公开以 Release 页面为准。

标签流水线先运行完整 Desktop 门禁，再构建安装器、核对物料并从 DMG 隔离安装和启动；发布任务复用这些原样安装包。系统通知权限、声音、输入法和真人体验的检查范围另见[测试与 CI](../测试与CI.md)。本版没有前一正式版本，不将开发候选的升级测试解释为正式跨版本迁移承诺。

## 版本边界

无需登录，没有账号或云同步；云同步属于 2.0.0 路线。首次正式资料使用稳定的 `workspaces/v1` 空间，保留旧未发布测试库而不迁移。后续已发布版本必须保护这份正式资料。
