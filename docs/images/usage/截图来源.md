## 复现

准备 JDK 21、当前前端和 Core 后，在 Desktop 仓库执行：

```bash
npx playwright test --config playwright.desktop.config.cjs tests/desktop001/docs-note-capture.spec.cjs
```

默认输出到 `test-results/docs-demo`，可通过 `LEXIMEET_DOCS_CAPTURE` 指定隔离输出位置。连接图片需要同时启动真实 Browser 专项环境；参见[后台自动化测试](../../测试与CI.md)和[插件连接](../../插件连接.md)。

当前手动采集等使用图可以运行 `npm run test:visual` 复现，`LEXIMEET_USAGE_CAPTURE` 可指定本轮输出目录。不要为了重拍图片接触日常剪贴板、正式用户资料或已暂停修改的 Browser。
