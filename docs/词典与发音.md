安装包携带 Core 只读索引、压缩源分片与许可。首次不依赖在线下载；Core / Full 安装复用同 SHA 文件，只补缺失资产。安装前按 Core 至少 1 GiB / Full 至少 2 GiB 可用空间保守检查，构建在临时空间完成。构建校验全部长度、哈希、v2 结构、目录与数量后，才切 active 指针并重新挂载 Core；失败 / 取消保留当前版本，上一版本可回退。

条目原始 v2 JSON 保留并压缩，按词解压；目录保留成员顺序、sense_ids 与 source_payload。lookup_key 用于搜索，entry_id 用于身份，A / a 不能合并。0.0.3 之后的清单必须单独核验再更新固定发布合同，不通过任意 URL 导入未知版本。

## 实际发音

- 有道：真实 dictvoice 词音，美式 type=2、英式 type=1；默认选有道、美式，允许失败时尝试备选。
- 微软：自行实现 Edge Read Aloud 兼容 WebSocket 适配，四个英美 Voice，接收真实音频帧、turn.end、有界超时与取消；参考 Aictionary 的协议思路。
- 自定义：HTTPS，或开发时本机 HTTP；GET URL 模板、POST JSON 模板和 Headers。响应必须是实际 MP3 / WAV / Ogg 音频，JSON 或异常页会被拒绝，单次最大 2 MiB。尚未实现返回下载链接的 JSON 或持续流式播放。

模板可以使用 {word}、{accent}、{voice}。GET 正确编码文本，POST 将占位符替换为 JSON 字符串值；不是执行任意脚本。自定义服务的 Key / Authorization 放在 Headers 文本中，保存后输入框清空；已有密钥不返回 Renderer，可明确清除。

Main 使用 Electron safeStorage 加密 Headers；若当前平台不能安全加密则拒绝保存密钥，不降级成明文。业务备份不携带设备凭证。网络请求默认只发词头，不包含私人语境、笔记或学习历史。

缓存为有界内存缓存，最多 128 条 / 32 MiB；设置提供真实清理。播放中能看到加载、播放与失败状态，换页、换词和取消会停止旧音频并丢弃迟到响应。只有当前 Audio 的 ended 自然结束事件提交 Main 发放的一次性 completed 回执，才推进发音教学并放烟花。获取音频或 play() 成功都不算完成；切换口音、取消、失败和迟到回执不会提前推进。

此前实际请求有道与微软获得可解码音频，原生自动测试另用自有本机 WAV 服务验证播放回执。前者验证外部服务当前可用，后者验证 Main / IPC / Renderer 链路，二者分别记录。

Edge 兼容服务不同于需订阅密钥的 [Azure Speech REST API](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/rest-text-to-speech)。[Edge Read Aloud 产品说明](https://support.microsoft.com/en-us/edge/use-immersive-reader-in-microsoft-edge)不意味着兼容端点有长期 SLA；配置可以切换和自定义，不把现在可免费调用写成永久承诺。
