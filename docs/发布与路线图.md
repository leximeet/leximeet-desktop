# 版本路线与发布门禁

本地正式版本：1.0.0；本地协议 LMCP 1.0.0。应用、协议、Dictionary 0.0.3 和数据库格式各自管理。远端发布尚未执行。

| 阶段           | 内容                                           | 交付条件                                       |
| -------------- | ---------------------------------------------- | ---------------------------------------------- |
| 0.0.1 基线     | 本机词典/规划/六练习/资料/采集/教学            | 历史自动回归与用户体验确认                     |
| 1.0.0 本地连接 | 配对、网页读取采集、插件 A 封存/恢复、桌面 B+C | 真实生产插件链路、故障恢复、随包环境和人工验收 |
| 2.0.0 云同步   | 独立设备登录、授权上传、事件合流和恢复         | 双独立设备/真实云数据库/账号权限/离线一致性    |
| 后续扩展       | 其他 OS、IDEA 等插件、宿主能力                 | 实际实现与独立平台验证                         |

## 1.0.0

1. 本地连接不需要云账号；配对有来源与范围限制，用户可断开或撤权。
2. 连接前 A 封存，桌面 B 不变；没有导入/合并步骤。连接新增 C 到桌面，明确断开恢复 A。
3. 插件网页入口通过 ReadingPort/CapturePort 使用桌面资料，管理和学习打开桌面。
4. 临时失联保持桌面归属；稳定 mutationId/eventId 防重，未知结果查回执，不自动改写独立库。
5. 桌面本机六练习、规划、积分和 FSRS 继续独立工作，不要求在 LMCP 中再次实现。
6. browser/1 反向网页调用可选，只使用插件实际注册并授权的能力。本轮 Browser 基础连接不注册该扩展，不能宣传已有网页高亮/选区产品功能。
7. 首先验证 macOS + 独立 Chromium；源码联调与真实 app 内 JRE/外置 Host 分别执行。

最新逐层测试证据见[1.0.0 验收](测试与CI.md)。协议参考/Schema、模拟客户端、真实 Core、原生单端、真实 Browser 与打包环境结果不能混算。自动化保持隐藏、静音、全周期焦点证据；日常资料和系统键鼠不参与。

正式发布前还须用户验收通知权限/真实剪贴板/快捷键/声音、确认签名安装物以及公开历史内容。macOS 以外没有实际验收，不能推断通过；正式签名、公证、商店和发布需单独授权。当前禁止推送或开 PR。

## 2.0.0

独立插件和桌面作为平等设备，账号与同步分别管理。用户选择云覆盖或合并；普通可变资料发生冲突时以云端为准，学习事件按 ID 汇总。首次上传先处理最近 3 天，再处理 3–7 天及更早的数据，按字节分页、补齐依赖并保留检查点。同步由用户主动点击触发，恢复独立模式后不会自动同步。

公共资源版本不一致时，不丢弃私人资料；保留稳定词身份、语境和笔记，使用可用资源的交集展示和出题。不同账号不会隐式合并，连接插件不取得桌面的长期云凭据。2.0.0 需要验证正式 1.0.0 资料的首次同步、离线合流、重复提交、撤销删除、快照和跨语言 FSRS 一致性；本地连接通过不能代替云端验收。

## 数据政策

当前直接初始化 schema 100，不维护 0.x/rc 测试库或旧协议双栈。未知格式拒绝并保留，不自动清库。同模型重启、草稿、事务与回执恢复必须正确。正式 1.0.0 之后维护真实资料升级，云同步不能重置已发布数据。

## 从历史设计保留的待办

| 方向                                     | 真实交付条件                                                                         |
| ---------------------------------------- | ------------------------------------------------------------------------------------ |
| Windows / Linux、Chrome / Edge 矩阵      | 各 OS 的打包 Java、Host 注册、安装/升级、通知权限和 UI 实机验收                      |
| 独立设备云同步 2.0.0                     | 稳定身份/事件/tombstone/检查点、账号权限、主动同步、云覆盖或云优先合并、离线冲突测试 |
| 首次历史上传                             | 先最近 3 天、3–7 天再更早；按字节分页、补依赖、可续传，不丢旧笔记                    |
| 不同公共词典版本                         | 云保存个人事实并集，可用资源交集用于展示/出题；保留未知词引用，不删除用户内容        |
| browser/1、IDEA、VS Code、WPS 等宿主能力 | 各插件自行注册实际能力，显式授权，真实宿主验收，不把可选 Schema 当成功功能           |
| 关系词典与句子学习                       | 根词/搭配/WordNet 来源、许可和离线索引；新增学习规则独立设计                         |
| 可访问性与统计                           | VoiceOver/NVDA、缩放、对比度、减少动画；区分完成词数、练习数和遗忘趋势               |
| 应用/内容更新与恢复                      | 区分应用包、公共资源和个人同步；磁盘不足、取消、损坏、回退和重启检查                 |
| 可选翻译/AI 服务                         | 用户启用、密钥隔离、来源标注、超时/费用说明；不默认上传私人语境                      |

旧的首次连接合并、插件接管完整学习 API、旧 20 分满分和 0.x 测试库转换不再作为任务。应用尚未正式发布，不承诺兼容开发候选库；正式 1.0.0 发布后才维护真实升级承诺。

其他宿主可保留的具体场景：IDEA 的注释/标识符、当前文件或选中行、来源定位和编写时勿扰；WPS 的选区/段落、Word/PDF 摘录与页码，不修改原文档。它们需要独立的宿主 API、权限和真实环境验收，不能继承旧原型中的手动配对码或资料合并。

看词选义题需对同形多义与相近干扰项做人工质量抽审；字符串去重和有效释义校验不能保证每题语义无歧义。

按需保留的探索：用本轮错误/提示/跳过归纳待巩固词和可选小结，不加回繁琐计时开始屏；扩充连字符、弯引号、Unicode 与短语输入向量。未来移动端以近期任务/目标按需取得词卡、语境和音频，不照搬桌面 Full 整库；任务身份与可重建缓存分开，需真实移动宿主验收。
